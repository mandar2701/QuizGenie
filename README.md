# 📘 AI-based E-learning Quiz Generator  

## 🎯 Project Goal  
This project is a smart **web/mobile application** that helps teachers and educators generate **quizzes (MCQs)** automatically from study materials like **text, PDFs, or notes**.  
It uses **AI/NLP techniques** to identify key concepts and create meaningful questions, saving time for teachers and making learning more interactive for students.  

---

## 💡 Example Use Case  
A teacher uploads a chapter from a textbook (e.g., *“Photosynthesis in Plants”*).  

The system processes the content and generates questions like:  

**Q:** What is the primary pigment involved in photosynthesis?  
- a) Hemoglobin  
- b) Chlorophyll ✅  
- c) Glucose  
- d) Oxygen  

---

## ⚙️ Features  
- 📂 Upload Study Materials – Supports text and PDF uploads.  
- 🤖 AI/NLP Question Generation – Extracts key concepts and generates MCQs.  
- 🎓 Educator-Friendly – Helps teachers prepare quizzes quickly.  
- 📱 Web & Mobile Support – Can be built as a full-stack app.  
- 📝 Customizable Quizzes – Teachers can edit generated questions.  
- 📊 Analytics (Future Scope) – Track student performance on generated quizzes.  

---

## 🛠️ Tech Stack  
- **Frontend:** React.js   
- **Backend:** Node.js 
- **Database:**  MySQL   
- **AI/NLP:** Python (NLTK, spaCy, Hugging Face Transformers, OpenAI API)  
- **File Handling:** PDF.js / PyPDF2  

---

## 🚀 How It Works  
1. Teacher uploads **study material (PDF/Text)**.  
2. Backend processes text → extracts keywords & concepts.  
3. AI/NLP generates **questions + multiple-choice answers**.  
4. Teacher can review/edit questions before finalizing.  
5. Students can attempt quizzes in the app.
